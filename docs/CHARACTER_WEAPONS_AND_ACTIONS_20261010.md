# 人物武器与攻击素材制作方案

## 2026-10-11 最新覆盖规则

- 港口／探索行走使用空手版本，不展示战斗武器；战斗场景才使用持械待机与移动。船主的对白佩刀保持完整入鞘、腰侧悬挂、双手放松。
- 远程射击改为八方向。按相机方位选择 S/SE/E/NE/N 源方向及对应镜像，瞄准、出手、收势和弩口锚点必须一致；一次已开始的射击保持方向。近战仍只需右向源动作和左向镜像。下文原“攻击左右即可”仅继续适用于近战。
- 已制作的阿棠持弩转面图归于战斗源图；探索空手源图单独生产。原素材与已提交视频保留，不混作另一种状态。

2026-10-10。用户已接受阿棠新的 imagegen 立绘，并要求先考虑武器是否合理、持械源图和攻击动作如何生产。本文是当前设计与制作约束，未将武器提案、时间参数或历史形制冒充已经验收的成品。

## 1. 已确认的人物基准

阿棠是老梁的女徒弟，熟悉船具，主动与主角合作救师傅；在海上负责炮位支援，接舷承担远程支援。已接受立绘：`Assets/Characters/Working/Atang/portrait-master-v01/atang-portrait.png`，原图 SHA-256 为 `e1e7ed3b5b71354129fc8b77920be8f3c938cd56a415febee1a04acb94f49533`。

后续保持同一张脸、发型、衣服、配色和绘制语言。腰间锤、绳与修船单用于表达船匠身份，战斗主武器另做明确设计。不会因为立绘上有锤，就更改她既有的远程职责。

## 2. 首版武器建议

建议阿棠首版使用**原创中式单发轻弩**。理由是她的角色重点在于熟悉器械、靠站位和时机提供精准支援；持弩待机、瞄准、击发和装填可形成清楚的图形状态，并与主角近战区分。

这只是与人物和玩法匹配的原创提案，不声称它是某年某地船匠的标准装备。具体年代尚未确定，不提前命名成某个制式历史名弩，也不做现代复合弩的滑轮、瞄准镜和导轨外形。

| 选择 | 对当前角色与玩法的意义 | 本轮判断 |
| --- | --- | --- |
| 单发轻弩 | 器械感鲜明，攻击和装填状态易辨；可把压制技能表现为一次更充分的瞄准与配合 | 当前优先方案 |
| 弓 | 拉弓、放箭的身体动作表现强，但需要更大的动作展开空间和明确的弓手训练背景 | 保留给另一类角色或后续替代方案 |
| 鸟铳／火绳枪 | 与明代海战和火器主题相关，击发反馈有特色；需要匹配年代、装填演出和烟火层次 | 后续有明确设计需要时再采用，不能当作快速连发枪 |
| 木槌／修船工具 | 能表达她的职业身份 | 作为道具保留，不因此改变远程定位 |

主角现阶段继续采用单手刀的近战动作方向；头目与随从的兵器可通过姿态与轮廓区分，但本轮不扩成多武器装备系统。狭窄甲板上的长兵器、盾牌等需要另验证通道和动作空间。

### 历史资料的用途和边界

- 中国国家博物馆《青铜弩机》说明弩是古代发箭兵器，弩机是机发部件。该藏品为三国时期，本文只以它核对基本分类，不能把其具体样式称为明代复原。[藏品说明](https://www.chnmuseum.cn/zp/zpml/csp/202008/t20200826_247436.shtml)
- 中国航海博物馆 2020-08-25《古代单兵海战火器——鸟铳》讨论明代海船使用鸟铳，并列出《筹海图编》《纪效新书》《神器谱》等参考。本文只采用“明代海战存在鸟铳应用”这一背景判断，不照抄全部性能叙述或把馆藏图当作任何开局年份通用的装备。[博物馆原署名文章](https://m.thepaper.cn/baijiahao_8866953)
- 冯震宇《明代鸟铳的技术谱系及战争实践》，《自然科学史研究》2022 年第 41 卷第 3 期，山西大学科学技术史研究所的作者论文介绍将鸟铳说明为明代火绳枪，并讨论其地域和战争实践。使用火器前仍需对照最终故事年代。[作者机构页面](https://ihst.sxu.edu.cn/kycg/lw/32be75398657430196f2d7f9babeb3e3.htm)

## 3. 图片先解决人物和武器的一致性

全部图片由 **imagegen** 生成，本地 MiniMax H3 只制作视频。

1. 以已接受的阿棠立绘为人物身份参考，制作同一人的持弩设定图。保持脸、发型、衣装和工具，替换手里的临时道具并调整双手姿势。先看人物与武器是否协调。
2. 固定弩的外观、相对身体大小、弩身／弓臂轮廓、持握位置和携带状态。形状和尺度需要在画面中便于辨认，并能通过握持与动作检查。
3. 按实际游戏镜头制作单人、单方向的持械待机源图。角色、双脚和整个武器处于画布内，动作方向有足够留白。
4. 再制作瞄准或出手前的关键姿势参考；关键姿势也须使用同一人物和武器设计。不得让视频模型从空手立绘自行发明武器。

同一人物的港口携带、战斗待机、移动、射击和受击应有连续的武器状态。避免走路时空手、攻击时突然多出一把弩，也避免每个动作换一种弩。

## 4. 将视频拆为可操作的短动作

阿棠初步需要：

- 持械待机：轻微呼吸、稳定握持。
- 举弩与瞄准：重心和视线指向目标，武器轮廓清楚。
- 单次击发与收势：清楚的一次释放、克制的身体反馈，没有枪械式大后坐。
- 装填与恢复：独立、可辨认的动作段，结束时回到可再次攻击的姿态。
- 持械移动、受击、倒地：在射击样本通过后补齐；移动仍按既定八方向流程。

首个视频任务只检查一次举弩—瞄准—击发—收势，不混入跑动、敌人、闪避、转场或烟火。装填另做一段；多项动作塞入同一长视频容易变成不适合游戏操作的表演。

攻击先制作右向源动作，左向采用既定镜像方案。镜像会改变持械侧，这是当前已接受的制作简化；出箭点等锚点也要同步镜像。一次动作中稳定朝向，避免敌人在屏幕中心两侧移动时人物反复左右翻转。

视频输入使用单个人物、单个方向的清晰图片，不能把八方向拼图直接交给 H3。锁定镜头、人物尺度与地面根点，保留原视频和完整帧；不按每帧可见包围盒自动居中，不消除有用的身体起伏。

## 5. 动作事件与玩法状态分开

基础状态可以组织为：持械就绪 → 准备／瞄准 → 击发 → 恢复／装填 → 就绪。动作时长要由合格片段与正常速度手感共同决定；现有每 1.8 秒一次的数值只是规则占位，不能迫使装填演出不合理地闪过。

普攻和压制射击共用同一武器装填状态。技能冷却完成不代表一把未装填的武器能凭空再发一箭。压制的差别主要体现在目标、瞄准、击中后的效果和协同，不必为了技能换一把新武器。

从通过的片段中记录：

- 固定地面根点和全动作包画布。
- 击发帧／事件时刻，以及该帧的弩口位置。
- 回到待机、允许移动取消、装填完成等明确时刻。
- 左右镜像时的朝向与锚点变换。

Godot 在击发事件创建真实箭矢，由空间运动和碰撞决定命中。H3 片段只表现人物与武器，不生成飞向敌人的整段箭矢，也不预先画入命中火花、伤害数字或敌人反应。射击一旦发生，之后的移动或动作切换不能撤销已经飞出的箭；事件必须只触发一次，暂停和子弹时间下也保持一致。

射程之外还要检查船舱、桅杆等实体遮挡及可接敌位置。不能只因为目标在距离范围内就持续向挡住的方向射击；箭矢的实际空间检测、寻路站位和玩家看到的射界提示需要一致。

近战同样单独管理攻击有效时刻、距离和范围；刀光是反馈，不能拿亮光图的大小替代攻击判定。

## 6. 样本验收再扩展

前一条新刀击候选曾出现大块自带刀光、越出画布及过度转身，已标记不采用。后续样本须检查：

- 正常速度下动作是否可读，准备、出手与恢复是否连续。
- 人物面孔、衣装、武器的形状与大小是否稳定。
- 手是否抓住同一个位置，武器有没有软化、复制、消失或穿过身体。
- 全动作是否留在画布内，脚底是否稳定，回位是否自然。
- 透明边缘、黑白底、左右镜像与实际游戏尺寸是否合格。
- 接入真实甲板后，出箭位置、目标方向、遮挡、狭路站位与命中反馈是否对应。

单个射击样本通过后再补完整动作组；不以文件生成成功或素材数量代替视觉与玩法评审。
