## 2. HD-2D 的关键，不是单一相机角度

Square Enix 官方将这套视觉描述为像素绘制与 3DCG 的结合；《八方旅人 II》还强调像素细节和镜头表现的进步。开发团队访谈强调的是如何让像素人物与三维背景融为一体，而非仅开启某种滤镜。[官方说明](https://www.jp.square-enix.com/octopathtraveler2/about/)、[开发团队访谈](https://www.unrealengine.com/en-US/developer-interviews/octopath-traveler-ii-builds-a-bigger-bolder-world-in-its-stunning-hd-2d-style)

从实际画面得到的项目判断如下。这些是视觉分析，不冒充官方给出的统一参数标准。

| 要素 | 好的参考怎样成立 | 港口 v02 的主要差距 |
| --- | --- | --- |
| 绘制语言 | 像素以成组色块描述轮廓、体积与材质，人物和环境的细节密度相互协调 | 人物和树偏细腻手绘，屋顶和船偏平滑三维，地面又是连续纹理；并排时缺少共同笔触 |
| 构图 | 前景遮挡、中景活动区、远景体量构成纵深；同屏有明确主次 | 两栋同源房屋、若干树、船和道路像均匀摆放的展示对象；空草地／水面占比大 |
| 镜头与角色 | 角色的脸、服装块面、动作在正常游戏尺寸下能被看清；立面和高差帮助建立空间 | v02 总览人物约占画面高度 6%，细节缩没；镜头主要说明物体位置，没围绕人物活动组织画面 |
| 几何与纹理 | 三维轮廓负责屋檐、台阶、船身等主形，纹理在这些形体上形成有节奏的块面 | 房屋模型的立面和屋顶、简化船舱／棚顶／岸石没有共同造型标准；增加木纹也不能修正形体 |
| 光照 | 光线挑出活动区、门口或船体；檐下、物体接地与远处明暗组织一致 | 有投影，但总体明度和色相比较平均；角色受光仍偏整张贴片变化 |
| 水和地表 | 波光、深浅、接触与倒影有主次，平静色面留给构图 | 反射已经存在，但水和岸沿仍太均匀；草地的小细节覆盖大面积，缺少受用途约束的变化 |
| 后期 | 雾与景深强化已有距离，辉光强调真正亮源 | 加后期只能软化已有形体，不能生成缺失的美术关系 |

当前镜头实际是约 **28° 俯角的正交斜视**，并非垂直向下；但“像普通俯视素材场景”的观感成立。正交投影本身不排斥这种美术表达，也不能把低俯角透视当成 HD-2D 的必要条件。《三角战略》官方图在较高俯角下仍有清楚的像素角色、建筑立面、坡路高差和前景遮挡；仅凭截图不能判断它的精确投影模式。[官方城镇图](https://www.square-enix-games.com/en_US/games/triangle-strategy)

## 3. 实际 Godot 对照：只换镜头为什么不够

保持 v02 素材、布置、灯光与角色姿态不变，做了三张 1600×900 的 GPU 截图。反射相机同步切换了投影与 FOV，避免把错误反射当成相机效果。

| 对照 | 实际改动 | 看到的结果 |
| --- | --- | --- |
| A · v02 原镜头 | 正交、俯角约 28°，无景深／辉光 | 能看清位置，但平铺感强，人物小，绘制语言不统一 |
| B · 只改相机 | 透视 FOV 35°、俯角 16°；近似保持焦点平面的垂直取景范围 | 房屋立面和前后尺度更明显；同时暴露空背景、地形边缘和缺失的远景，素材问题仍在 |
| C · 再加景深 | B 的相机加近／远景深，blur amount 0.10 | 前景船被明显模糊，主体可读性下降；这组效果不采用 |

这不是完整的“透视优于正交”实验：改变了投影和俯角两个因素，构图也没有针对新镜头重做。它只回答一个较小的问题：**保持现有素材布置，仅靠换镜头和加景深，不能得到目标画面。** 文件名里的 `mild-dof` 是试验命名，不能当成对最终模糊强度的美术评价。

对应原图与参数见对照页和 `Artifacts/HD2D-Research-20261009/harbor/diagnostic.json`。

## 4. 参考 Godot 工程：哪些技术确实有用

### 镜头与远景

参考工程默认 F 镜头为透视 FOV 35°、俯角 14°；另有更宽取景。背景按城镇、山、云组织成多层，而非只增加一块天空颜色。关闭景深和辉光之后，其绘制边缘仍然存在，说明像素感首先来自素材与采样。

但该工程默认总景也存在很大的空铺地区域、重复树形、简化山体和较重的雾。它适合验证镜头、受光和图集的配合，不应成为本项目最终美术质量的上限或整套照抄对象。

### 人物动态受光

工程把颜色、法线、银饰区域三种图集使用同一动作帧和 UV 区域。法线描述脸、发束、衣褶的方向，材质区域另行控制粗糙度与高光；角色的竖直朝向在主视图与阴影处理间保持一致。原生空间灯光参与照明。

实际做了固定姿态、固定相机、去掉原图颜色的对照：关闭太阳和环境灯具，只保留白色测试点光源与少量环境光；关闭雾、景深和辉光。法线开启时能看见脸部、头发和裙摆的明暗体积；关闭后变成平面轮廓；把点光源移到另一侧，明暗方向随之变化。第一轮光源过强，随后降低到 0.70 重新拍摄，旧图保留在 Local，不拿曝光过亮的版本作为主证据。

这说明技术有价值，但还没有验证我们的人物法线。它也不会自动解决人物原图已经画进去的阴影、逐帧体积跳变、左右镜像后的法线方向或投影轮廓问题。

下一步人物材质只验证一个代表姿态：先比较原图、弱受光、体积法线三个状态，再测左右／上方光照和镜像。通过后再做一个短动作的时序一致性，最后才考虑完整八方向动作。不能把颜色灰度直接当成体积，也不先批量生成上千张法线。

### 过滤与像素尺度

参考作者的像素颜色／法线／材质图集采用 nearest 采样。我们的 v02 为减少高分辨率木纹闪烁启用了 mipmap，这解决了一个运动问题，同时没有解决画法混杂。

不能据此得出“所有 mipmap 都关掉就会变成 HD-2D”。应先决定正常游戏尺寸下要看见的色块、线宽和角色有效像素高度，再分别处理角色、植被与斜视地面的采样。地面仍需缩小过滤与运动稳定性检查；角色不应因远距离缩小变成模糊色团。需要用实际步行和镜头平移判断，不能只看原尺寸贴图。

## 5. 河湾与五期日志怎样转为我们的制作方法

最有价值的是制作顺序。河湾画面先有成形的树、岩石、房屋、路和岸线，天气再改变这些形体的表面。港口 v02 则过早把精力放到反射、材质参数和道具补充，未先确定共享画法及主次。

| 研究内容 | 港口可以采用的原则 | 现在不应扩展的工作 |
| --- | --- | --- |
| 岸底与深度 | 先做有形状的岸、浅滩、桩和船体接触；三维深度参与水的透明度和色相，水底本身要可读 | 重新实现作者整套 2D 等距水位编辑工具 |
| 雨与积水 | 未来湿润变化应由覆盖区域控制，结合地物倒影；晴天基础材质先成立 | 以雨粒子、雷电或雾隐藏当前美术不足 |
| 夜空倒影 | 水面保留环境色，局部倒影服从表面运动；暖光集中在门口、码头等有人活动处 | 给明代港口直接搬来作者极光／星空风格 |
| 雪与季节 | 地面、树、房顶和光照要共同变化，保留道路可读性 | 在单张白昼样片尚未成立时做全年天气系统 |
| 场景布置 | 树石成组、建筑围合、道路留白，高差连接空间；避免均匀随机撒布 | 先做大地图、WFC、通用世界编辑器或大量建筑变体 |

纯 2D 的倒影、坐标旋转和遮罩不能直接复制到三维港口。应保留其分层思路，继续由真实三维空间处理船体、地面高差、遮挡与相机关系。

## 6. 下一份样片的具体美术方向

建议收敛到 **具有明确像素色块的绘制人物与植被，加有体积的建筑、岸台和船体**。保留精致感，但需要建立统一的轮廓、纹理节奏和色块尺度。现有高分辨率手绘资产可以作为素材来源候选，不能未经处理继续并排拼装。这是本次研究建议，尚未成为用户认可的最终画法。

下一份只做一个经过构图的港口局部：

1. **先确定画面。** 船和码头构成主要体量，人物活动区连接门口／岸台／登船处；前景用局部屋檐、桩或植物框景，远处有较低对比的屋顶、桅杆与岸线。避免把全村、整船和大量空海面同时塞进一个总览。
2. **先选取景尺度。** 在 1600×900 下，先试人物可见高度约 80–110 像素、俯角约 18–25°、透视 FOV 30–40°，并保留一个匹配构图的正交对照。这只是起测范围；最终由人物源素材角度、立面可读性和遮挡决定，不照抄教程参数。
3. **做最小的统一素材组。** 一名角色的代表姿态、一栋主建筑及相连的小体量、一组树石、一段岸台／码头、一艘船。把屋檐、树叶簇、岩面、船舷和人物服装放在同一游戏尺寸里检查。共享色板与笔触尺度比增加物件数量优先。
4. **先让白昼成立。** 一束方向明确的主光、克制的环境光与接触阴影，关闭景深和辉光。先把船体曲面、建筑檐下、人物脚底和岸水接触做好，再加局部灯光、远景雾及轻微景深。
5. **再做小段真实运动。** 人物走过明暗交界、树／檐下、码头和登船处；镜头只轻移。检查像素稳定、脚底、动作体积和前后遮挡，再决定扩充美术量。

船战远景需要另一套取景尺度，但应延续相同的材质画法与颜色关系；不能为兼顾整个海战场而把人物探索镜头拉得过远。人物战斗形式仍未冻结，这份建议不建立战棋或另一种战斗系统。

### 素材生产要改变的环节

| 部分 | 下一轮的具体做法 | 避免沿用的问题 |
| --- | --- | --- |
| MiniMax 人物 | 先用单个代表姿态确定有效像素细节和镜头角度，动作继续用原制作链；固定画布与地面根点，按共享色板整理色块；法线／材质区域与颜色帧同步 | 直接把高分辨率原帧缩进很小的角色，或逐帧按可见包围盒缩放，导致细节丢失和身体晃动 |
| 建筑与船 | 生成模型只当起点。先检查屋檐、柱廊、船舷、甲板的主形与比例，再统一 UV／纹理密度、檐下暗部与边缘高光；船体保留可转向的真实三维体积 | 用一张更清晰的木纹替代船身设计；把模型生成成功等同于可直接进入目标画风 |
| 树石与小物 | 先定义大轮廓、叶簇／岩面和明确暗部，再增加少量细节。树种变化与相邻建筑按同一取景比例比较 | 每个素材单独生成得很细，最终各自具有不同光源、边缘和细节尺度 |
| 地面与水岸 | 用路面、墙脚、树根、湿岸、浅滩等明确区域决定细节分布；允许大块安静表面。岸沿要有宽窄、曲直和高差变化 | 全场等强度噪声、均匀草点和一圈恒宽亮边 |

这些步骤仍需要逐张视觉检查。AI 可以提供候选，自动缩色或 nearest 采样只能改变显示方式，不能代替对轮廓、色块与时序一致性的整理。先在 Working 做最小试验，不改写已认可的 Library 源素材。

### 继续制作前的判断顺序

| 顺序 | 需要看到的证据 | 不通过时应改什么 |
| --- | --- | --- |

| 2 | 角色／树／屋顶／船体在同一缩放下属于同一套绘制语言 | 源素材与纹理处理；不统一套后处理滤镜 |

静帧成立后再决定昼夜、美术变体和远景船战镜头。功能测试继续用于输入和几何正确性，不能替代这四项画面判断。
