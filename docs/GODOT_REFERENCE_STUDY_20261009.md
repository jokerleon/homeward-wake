## 对目标画面的理解

- 不是让所有素材套一个屏幕像素化滤镜。目标是能辨认的绘制形体、统一的笔触尺度和稳定的空间关系。
- 水首先有深浅和接触关系。近岸能看到部分岸底，建筑、树和船的倒影随表面轻微变形；亮纹应有疏密，不把全海面铺成同一种短划线。
- 人物、植物和三维建筑共用环境明暗。冷暖灯光能影响角色，阴影方向一致，人物进入遮挡区域应正确变暗。
- 同一幅画面里有前景框景、中景活动区域和更安静的远景；码头货物、台阶和灯笼按用途布置，避免均匀撒满装饰。
- 第一轮仍是架空港口局部，不由视频中的四季展示扩成完整天气、编辑器或战斗项目。视频中的服饰、建筑和地理也不当作明代史料。

## 本地实现原则

港口保留真实 3D 地面、船体、建筑和二维人物/树。水采用真实场景深度与单独反射视口；这是对分层思路的本地实现，并非照搬纯 2D 深度贴图工程。精灵使用稳定竖直朝向和原生灯光，先解决接光/投影，再讨论逐帧绘制法线与金属材质蒙版。

深度重建按 [Godot 官方 reversed-Z 文档](https://docs.godotengine.org/en/stable/tutorials/shaders/advanced_postprocessing.html) 核对；反射视口按 [Viewport 官方说明](https://docs.godotengine.org/en/stable/classes/class_viewport.html) 共用三维世界。没有引入新的付费插件或新建收费生成任务。

## 基线问题与验证要求

基线的水过亮且均匀，船旁是人工椭圆亮圈；直长岸线与重复树房让画面像素材排布。船的帆、甲板和船舱仍然偏简模，树和人物原来不接收三维灯光。

迭代需要保存实际 Godot 截图与正常动作速度的录像，明确标注白昼、傍晚、近景及可比较的基线。编译成功不等于视觉合格。完整逐帧法线、美术终验、历史考据和战斗均不在这份结果中自动宣称完成。
