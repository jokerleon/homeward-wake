## 对话与故事

采用底部横向对白框、说话人名字、头像和少量明确选项。港口初遇、阿棠入队、航前选配、敌船停航、接舷救人、归港各一个短节点。对白确认与任务推进独立，跳过只提交一次。第一版不做配音、口型或复杂好感度分支。

主线：老梁被扣去修敌船→阿棠带路并担任炮位→主角答应救人→出航选船体加固或炮架改良→海上迫停敌船→选择追击／守望成长→登船救人→师徒归港，修船单货印留下后续线索。逃脱海战可以继续航行，但救人目标仍未完成。

## 船与炮弹

使用现有三维船模型作为两艘测试船的基础，加简洁旗色区分与炮位。炮弹是小型三维球体，带短尾迹；炮口闪、烟、木屑与落水水花由 Godot 生成。不是播放一整段海战视频。

- 开炮前可预估目标当时的速度；发射后弹道固定，不跟踪船只。
- 按炮弹连续经过的空间与船体碰撞体相交判断直接命中，不在发射时提前扣血。
- 高速炮弹做运动段检测，避免只查每帧终点而穿船；命中只结算一次。
- 船转向或变速后若离开弹道，炮弹继续飞行并落水，普通落水不产生范围伤害。
- 本次不做爆炸弹。压制弹只改变命中后的船员效果；弹种名称是游戏功能，未作历史断言。
- 换弹于下一轮装填生效，不能修改已经装填或在途的炮弹。
- 子弹时间同步缩放船速、弹速、装填与脱战计时。暂停／慢速不能凭空产生额外机动距离或改变碰撞结果。

海上保留航向、转向速度、自动舷炮和撤离优先级。脱战不重置船况、消耗、技能或敌船身份。在途攻击不因越界被删除。
