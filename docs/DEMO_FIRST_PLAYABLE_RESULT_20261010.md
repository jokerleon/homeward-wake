# 《归港的人》首版运行记录

日期：2026-10-10。第一步已落实为角色／技能／对白／弹道规格，以及独立的可操作故事流程。角色独立美术、正式攻击动画与完整演出尚未完成，不把当前版本当作全套 Demo 美术已验收。

## 启动与操作

```powershell
./tools/godot-demo.ps1 -Mode Play
```

新入口是 `Godot/return_demo.tscn`。原 `Godot/quay.tscn`、项目默认入口和 v03 启动器保留。

| 操作 | 用途 |
| --- | --- |
| WASD、E | 港口移动、交谈、推进对白 |
| 右下角任务按钮 | 交谈、出航、迎战、登船、确认布阵 |
| 点击己方人物／船／左侧头像 | 进入慢速指挥 |
| 点击地面／海面 | 部署或移动，人物移动后保持驻点 |
| 选中己方后点击敌人 | 指定目标 |
| 自动／保留、施放技能 | 调整技能使用方式，手动也遵守冷却与射程 |
| 右键／Esc、空格 | 取消指挥、暂停／继续 |
| F5／重试本段 | 返回检查点，保留该点的选择和状态 |

流程：港口交谈→阿棠入队→船体／炮架选配→原海域交战→敌船停航→人物成长选择→甲板布阵与自动即时战斗→救人归港。海战可撤离，脱战后继续航行，救人目标不会自动完成。

目前内容量小于原 15–20 分钟设想。自动推进对白的录像用于核验流程，不代表首次游玩时长，更不证明趣味性已通过玩家验证。

## 统一美术与真实甲板

用户明确要求后续统一使用已通过的 v03 风格，包括水体与航迹。最初用于接入规则的独立木板平台和另一套简单海水已撤出运行方案，相关旧图片只保留为诊断记录。

- 港口沿用 v03 场景、材质、植被、灯光与人物显示方式。
- 航行使用原三维船；甲板战使用从同一模型派生的收帆状态。原船体、甲板、船舷、舱室、纹理与 UV 保留，重建收帆束、桅杆和索具，腾出人物战斗视线。
- 人物脚底和部署显示依据原船网格测得的甲板高度放置，没有用矩形平台替代船。
- 海战水体继承 `quay_ocean.gdshader` 的色彩、绘制细节、深度和反射方式。独立 Demo 着色器增加船首／船侧扰流与尾迹，并针对航行镜头降低细碎闪点。
- 航迹记录船实际走过的位置，转弯形成曲线，速度影响强度，旧痕迹逐渐加宽消散。连续形状合并消除了首轮采样形成的重复圆圈。

原 v03 资源与原船 GLB 未覆盖。收帆派生模型的来源、SHA 和制作方法见 `Assets/HarborTrial/demo/boarding-ship-production-v2.json`。同风格不等于新场景已获用户认可；船背面、遮挡、炮烟与水花仍需实机试玩评审。

## 炮弹与脱战

炮弹是实际运动的三维物体。发射后弹道固定，运动段与移动船体相交才扣血，防止高速穿过船体；同一颗炮弹只结算一次。

船实际离开弹道时不会承受直接命中伤害；普通落水只有水花。能否来得及躲开，取决于距离、弹速、船速与转向。已验证发射后改变实际位置不会被追踪扣血；具体操舵闪避窗口仍需试玩调校，不能承诺每炮都可躲。

换弹影响下一轮装填，不改变已装好或在途的弹种。阿棠的压制齐射是瞄准／配合效果，消耗同一炮组的射击机会，不暗中改写已装弹种。实际驶离追击范围后可脱战，船况、敌船身份、装填和技能状态继续保留。

效果由 Godot 实现：刀光、压制标记、炮口闪与烟、炮弹、命中、水花及航迹。其中命中、炮烟、炮口火光、水花、泡沫与刀光共用一张内置 imagegen 绘制的六格图集；源图和完整提示词在 `Assets/HarborTrial/demo/Working/fx-v01/`。弩矢使用细长三维箭体，炮弹使用三维球体。反馈音为本地脚本原创合成，没有购买特效包或使用外部声音素材；声音和效果仍需精修。
