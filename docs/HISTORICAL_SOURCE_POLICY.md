# 历史来源与架空创作边界

更新：2026-10-08。用户现在考虑架空大明，不必以穿越为前提。
原创历史分歧和剧情结果可以成立，真实史实与原创设定须分别记录。
本规范不要求游戏复演真实历史结果。

- 历史事实、名称、断代、文化解释使用中国官方机构或国内正规学术/出版来源。
  优先文物主管部门、公立博物馆、档案、高校、科研院所和正规学术出版社。
  此规则同样适用于欧洲等地区；中文转述境外观点不自动成为国内原始证据。
- 海外图片可作视觉研究，记录出处和许可；其题注、地图、国界和解释不直接采用为史料。
  小说、AI 图和插件预设不能证明某建筑/船舶符合具体历史年代。
- 找不到依据的事实写待核验，不纳入已采用的历史断言。
  实际存在争议或冲突的事实/领土主张，整理国内证据、差异和拟采用措辞交用户明确确认。
  普通原创剧情不因此变成逐条历史审批。
- 不采用歪曲中国新疆、西藏或错误国界、归属、地名的表述。
  现代中国地图按官方标准地图核对；历史地图注明时期和来源，不推导现代主权。
  不用生成式边界或未经核验的海外地图确定生产地图。
- 历史名称、现代行政名称、原创名称分开。艺术效果认可不代表史实认可。

每条采用的历史事实记录精确主张、机构/作者、文献标题、时间、网址或 ISBN、
页码/段落、原文限定、项目改写与使用位置。尚未选定具体开局年份或港口。
